# aiJudge 利用ガイド

aiJudge は、提出した課題をその場で採点し、**理由付きで**返すシステムです。
プログラム・レポート・写真（手書き）を、ファイルでも**ブラウザのエディタ**でも出せます。
AI の判定は**提案**で、成績は担当教員が確認して確定します。

![提出の結果。観点ごとに判定と理由が付く](images/st-result.png)

立場に合わせて読んでください。

## 2 つの画面と役割

| 画面 | 使う人 | できること |
|---|---|---|
| **学習者アプリ** | 学生（教員・TA も試しに提出できます） | 課題を見る・提出する・エディタで解く・結果を読む・再確認を依頼する |
| **教員コンソール** | TA・教員 | 提出を確認して確定する・課題と日程を出す・コースの設定 |

URL はコースの案内（シラバスや初回の授業）で配られます。ログインはどちらも同じアカウントです。

| 役割 | できること |
|---|---|
| **学生** (learner) | 提出する・自分の結果を見る・再確認を依頼する |
| **TA** (assistant) | 上に加えて、**採点を確認・確定**する |
| **教員** (instructor) | 上に加えて、**課題・日程・受講者・ルーブリック**を設定し、**作業の記録と提出の類似**を見る |
| **管理者** (admin) | 上に加えて、コースを作る・利用者とログイン方式を管理する |

## 採点はこう進みます

```mermaid
flowchart LR
  A[提出] --> B[テスト実行など<br>機械の判定<br>数秒]
  B --> C[AI の判定<br>根拠付き<br>30 秒ほど]
  C --> D[担当教員が確認<br>→ 確定]
```

- **機械の判定**（テスト実行・形式検査）は提出直後に出ます
- **AI の判定**は「どの行を見て、なぜその段階か」を添えて返ります
- 確定するまで点は**暫定**です。確定すると教員の根拠が学生に表示されます
- 提出物は学内のサーバで採点し、学外のサービスには送りません
