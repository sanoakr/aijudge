{% if access.value == 'inside' %} この設定では学内と判定されます。 {% elif access.value == 'outside' %} この設定では学外と判定されます。学内の端末からこの画面を開くと、 登録すべきアドレスがここに出ます。 {% elif access.value == 'not_configured' %} 範囲がまだ 1 件も設定されていないので、制限は効いていません （学内限定にした問題セットにも誰でも提出できます）。 {% else %} 接続元が読めないため判定できません。逆プロキシの設定 （X-Forwarded-For）を確かめてください。 {% endif %}
判定に使うのは X-Forwarded-For の右端、 つまり逆プロキシが書いた値です。左端は接続してきた側が自由に書けるので使いません。
{# **NAT に注意する。** 無線 LAN の内側のアドレス（10.x など）をそのまま 書いても、変換されて届くなら 1 件も一致しない。上の「いまのアドレス」で 確かめられるようにしてある。 #}
無線 LAN の内側のアドレスをそのまま書かないでください。 端末に割り当てられるアドレス（10. で始まるものなど）と、 ここに届くアドレスは、間に NAT があると別のものになります。 学内の端末でこの画面を開き、上に出るアドレスを登録してください。

1 台だけなら /32（IPv6 は /128）と書きます。 読めない行があると保存できません ── 黙って無視すると、 抜けたことに気づかないまま試験を迎えることになります。 空にすると制限は効かなくなります。
